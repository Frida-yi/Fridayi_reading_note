# Chapter 2 - Financial Data Structures

## 1. 本章一句话总结

金融数据不能直接“拿来就训练”。要先把原始数据处理成连续、同质、可交易、尽量少噪声的结构化样本；核心方法包括：选择合适的数据源、构造 bar、处理多品种序列、以及对特征样本做事件采样。

---

## 2.1 Motivation

本章目标：从非结构化金融数据出发，构造适合机器学习算法使用的结构化数据集。

重点不是直接使用别人加工好的数据，因为那样大概率只能发现别人已经知道、或者很快会知道的东西。更理想的起点是：

```text
原始数据 → 自己清洗/结构化 → 生成有信息量的特征
```

对我的启发：

- Alpha158 是别人已经高度标准化的因子库，优点是方便，缺点是信息优势有限；
- 后续如果要提高模型上限，需要逐步往更原始的数据、更贴近交易过程的数据靠近；
- 但对日频截面选股来说，不一定一开始就上逐笔数据，先把日频样本结构、标签、采样、验证做好更重要。

---

## 2.2 Essential Types of Financial Data

书中把金融数据分成四类。

| 类型 | 内容 | 主要风险 | 对我的意义 |
|---|---|---|---|
| Fundamental Data | 财报、资产、负债、收入、利润、宏观变量 | 发布时间错位、回填、修正值导致未来函数 | 用基本面因子时必须确认真实发布时间 |
| Market Data | 价格、成交量、报价、订单、持仓、主动买卖方向 | 数据量大、结构复杂、清洗困难 | 日 K、分钟 K、逐笔、盘口都属于这里 |
| Analytics | 分析师评级、盈利预期、新闻情绪、信用评级 | 昂贵、黑盒、多人共享 | 信号可能已经被别人加工和消费 |
| Alternative Data | 卫星、搜索、社交媒体、地理位置、传感器 | 贵、隐私问题、工程复杂 | 难处理的数据反而可能有独特价值 |

### 关键笔记

1. **基本面数据最容易出现未来函数。** 不能把财报期末日期当作数据可用日期，必须使用真实披露日期。
2. 数据供应商可能会回填或覆盖历史数据。回测时如果用了后来修正后的值，就会把未来信息带入过去。
3. 越难处理、越难存储、越难清洗的数据，越可能有研究价值，因为竞争者更容易放弃或处理错误。

## 2.3 Bars

为了把原始交易数据变成机器学习可用的数据结构，需要构造 bar。

### 2.3.1 Standard Bars

常见 bar 类型：

| Bar 类型 | 采样标准 | 优点 | 问题 |
|---|---|---|---|
| Time Bar | 固定时间间隔，例如 1min、1d | 简单、最常见 | 低活跃期和高活跃期信息量差异很大 |
| Tick Bar | 固定成交笔数 | 比时间 bar 更贴近交易活动 | 大额成交和小额成交被同等对待 |
| Volume Bar | 固定成交量 | 比 tick bar 更考虑交易规模 | 不同价格阶段，同样成交量对应的资金量不同 |
| Dollar Bar | 固定成交额 | 更接近真实资金流，通常更稳健 | 需要成交额数据，bar size 需要设定 |

### 重要理解

1. 按时间采样得到的序列往往统计性质较差，比如序列相关、异方差和收益非正态。GARCH 模型在某种程度上就是为了解决这类采样带来的异方差问题。
2. 在固定交易笔数下，价格变动可能更接近高斯分布；在固定时间区间内，价格变动可能呈现厚尾。原因是固定时间内的交易笔数本身是随机的。
3. Tick bar 要注意异常大额成交。例如开盘/收盘集合竞价可能被记录成一笔 tick，但其规模可能相当于大量普通成交。
4. Volume bar 通常比 tick bar 统计性质更好，因为成交量比成交笔数更接近真实市场活动。
5. Dollar bar 在价格波动较大时更合理，因为它按实际交换的金额采样，而不是按股数或成交笔数采样。
6. Dollar bar 对拆股、回购、增发等公司行为更稳健。bar size 也可以动态调整，例如股票按自由流通市值调整，债券按未偿债务规模调整。

### 对我的日频截面选股的意义

- 目前使用日 K，本质上是 time bar；
- 如果主线是 A 股日频截面选股，短期不一定要改成 dollar bar；
- 但如果以后做分钟级 BTC、期货、黄金等交易，dollar bar / volume bar 会更重要；
- 对日频模型来说，更优先的是：标签定义、样本采样、样本权重、验证切分。

## 2.3.2 Information-Driven Bars

信息驱动 bar 的核心：不按固定时间、固定成交量采样，而是当市场中的买卖失衡、知情交易、成交方向异常等信息积累到一定程度时采样。

### Tick Rule

用 tick rule 判断成交方向：

\[
b_t=
\begin{cases}
b_{t-1}, & \Delta p_t = 0 \\
\dfrac{\Delta p_t}{|\Delta p_t|}, & \Delta p_t \ne 0
\end{cases}
\]

其中：

- \(b_t=1\)：买方主动；
- \(b_t=-1\)：卖方主动。

### Tick Imbalance Bar

累计 tick imbalance：

\[
\theta_T=\sum_{t=1}^{T} b_t
\]

当累计失衡达到预期阈值时生成 bar：

\[
T^*=\arg\min_T
\left\{
|\theta_T| \ge E_0[T]\cdot |2P[b_t=1]-1|
\right\}
\]

### Volume / Dollar Imbalance Bar

把成交方向和成交量/成交额结合：

\[
\theta_T=\sum_{t=1}^{T} b_t v_t
\]

预期失衡为：

\[
E_0[\theta_T]
=
E_0[T]
\left(
P[b_t=1]E_0[v_t\mid b_t=1]
-
P[b_t=-1]E_0[v_t\mid b_t=-1]
\right)
\]

### 关键笔记

Information-driven bars 的目标是捕捉异常成交行为，尤其是可能来自知情交易者的行为。它比标准 bar 更接近“信息到达市场”的过程。

对我当前系统的意义：

- 日频截面选股暂时不必优先实现；
- BTC/期货分钟级交易可以重点研究；
- 如果未来使用逐笔数据，可以基于 OBI、OFI、CVD、trade imbalance 等微观结构特征构造事件 bar。

## 2.4 Dealing with Multi-Product Series

这一节讲的是：当交易对象不是单一资产，而是价差、篮子、指数、期货连续合约、多空组合时，不能简单把价格拼起来训练模型。

正确做法是把复杂组合转成一条类似 ETF 净值的序列。

### 价差是什么

价差不是一个真实资产价格，而是多个资产价格的组合。例如：

\[
spread_t = P^A_t - w_t P^B_t
\]

常见例子：

- 买 BTC，卖 ETH；
- 买远月期货，卖近月期货；
- 买一组股票，卖另一组股票。

问题：

1. 价差可能为负，很多模型默认价格为正；
2. 权重变化可能导致价差变化，但这不是真实 PnL；
3. 多个资产交易时间不一定完全对齐；
4. 真实交易还要考虑买卖价差、滑点和成本。

### 篮子交易是什么

篮子交易就是交易一组资产，例如：

\[
50\% BTC + 30\% ETH + 20\% SOL
\]

指数、行业组合、截面选股的 TopK 股票、多空组合，本质上都可以看成篮子交易。

### ETF Trick

ETF Trick 的核心：

```text
假设一开始投入 1 美元，记录这 1 美元在复杂组合中随时间变成多少钱。
```

令初始净值：

\[
K_0=1
\]

组合价值更新：

\[
K_t
=
K_{t-1}
+
\sum_{i=1}^{I}
h_{i,t-1}\phi_{i,t}
(\delta_{i,t}+d_{i,t})
\]

其中：

- \(K_t\)：虚拟 ETF 净值；
- \(h_{i,t}\)：品种 \(i\) 的持仓数量；
- \(\phi_{i,t}\)：每一点价格变化对应的美元价值；
- \(\delta_{i,t}\)：市值变化；
- \(d_{i,t}\)：分红、票息、持有收益或融资成本。

### 对我的系统的意义

1. 截面选股最终交易的是动态股票篮子，不只是单只股票预测。
2. 回测净值应该严格按真实持仓、调仓、分红、停牌、交易成本计算。
3. 如果以后做期货，必须处理移仓；不能直接把主力合约价格粗暴拼接。
4. 如果以后做多空组合，可以把组合净值看成一条虚拟 ETF 序列，然后再做风险评估和模型分析。

## 2.4.2 PCA Weights

PCA weights 用来根据协方差矩阵的主成分来分配组合风险。

谱分解：

\[
VW = W\Lambda
\]

组合风险：

\[
\sigma^2
=
\omega'V\omega
=
\omega'W\Lambda W'\omega
=
\beta'\Lambda\beta
\]

其中：

\[
\beta = W'\omega
\]

因为 \(\Lambda\) 是对角矩阵：

\[
\sigma^2
=
\sum_{n=1}^{N}
\beta_n^2\Lambda_{n,n}
\]

第 \(n\) 个主成分的风险贡献：

\[
R_n
=
\beta_n^2\Lambda_{n,n}\sigma^{-2}
\]

如果给定风险分布 \(R\)，则：

\[
\beta_n
=
\sigma
\sqrt{
\frac{R_n}{\Lambda_{n,n}}
}
\]

再回到原始资产空间：

\[
\omega = W\beta
\]

对我当前系统：暂时不是第一优先级。后续做组合优化、行业/风格中性、多空组合风险分配时再深入。

## 2.4.3 Single Future Roll

期货会到期，因此需要移仓。直接把旧合约和新合约拼起来，会产生假跳空。

处理方法：

1. 构造累计移仓缺口序列；
2. 从价格序列中扣除移仓缺口；
3. 用调整后的价格计算 PnL 和 mark-to-market；
4. 但仓位大小和资本占用仍然应该使用原始价格。

注意：调整后的连续期货价格可能变成负数。更稳妥的方法是构造 1 美元投资净值：

```text
rolled price → return = rolled price change / previous raw price → (1+r).cumprod()
```

对我当前系统：A 股截面选股暂时关系不大；如果做黄金、商品、股指期货，这一节很重要。

## 2.5 Sampling Features

这一节对我的日频截面选股很重要。

我当前做法：

```text
每只股票、每个交易日 → 取过去 60 天日 K → 计算 Alpha158 → 生成训练样本
```

问题：

1. 相邻样本的 60 天窗口高度重叠；
2. 如果标签是未来 N 日收益，相邻标签也高度重叠；
3. 大量平淡行情会稀释真正有信息量的样本；
4. 模型以为样本很多，但有效信息密度可能不高。

### 2.5.1 Sampling for Reduction

普通下采样：

- 固定步长采样，例如每 5 天采一个样本；
- 随机均匀采样。

优点：简单，减少样本量。

缺点：太机械，可能采不到最有预测价值的时刻。

### 2.5.2 Event-Based Sampling

事件采样的思想：

```text
不是每一天都训练，而是在市场出现某些重要事件后才采样。
```

事件可以是：

- 结构性断点；
- 信号触发；
- 波动率放大；
- 价差偏离均衡；
- 微观结构异常；
- 收益累计变化达到阈值。

### CUSUM Filter

CUSUM 是累计变化检测器。它不是看到单日变化就触发，而是从上次重置后累计变化达到阈值才触发。

上行累计：

\[
S_t^+
=
\max
\left\{
0,
S_{t-1}^+ + y_t - E_{t-1}[y_t]
\right\},
\quad S_0^+=0
\]

下行累计：

\[
S_t^-
=
\min
\left\{
0,
S_{t-1}^- + y_t - E_{t-1}[y_t]
\right\},
\quad S_0^-=0
\]

综合统计量：

\[
S_t
=
\max\{S_t^+, -S_t^-\}
\]

当：

\[
S_t \ge h
\]

就保留该 bar，并重置统计量。

### 我的笔记

为了减少数据噪声，要对数据进行降采样，可以使用 CUSUM 过滤器来进行数据的降采样，这在过去的工作中被证明是有效的。

### 对我的系统的落地方式

先不要推翻 Alpha158，也不要马上改模型结构。第一版可以这样做：

```text
日 K → Alpha158 不变
训练样本日期 → 用事件采样/样本权重处理
实盘预测 → 仍然每天正常预测和排名
```

更适合截面选股的实验顺序：

| 实验 | 做法 | 是否破坏截面 |
|---|---|---|
| Baseline | 每个交易日都训练 | 否 |
| 市场收益 CUSUM | 对股票池等权收益或指数收益做 CUSUM，触发日保留完整截面 | 否 |
| 截面分散度筛选 | 当日个股收益分化较大时保留完整截面 | 否 |
| 样本权重 | 事件日权重大，普通日权重小 | 否 |
| 个股 CUSUM | 对每只股票单独采样 | 可能破坏截面 |

我优先尝试：

1. 使用股票池等权收益构造市场收益序列；
2. 对市场收益做 CUSUM；
3. 触发日期保留当天所有股票样本；
4. 非触发日期先不删除，而是尝试降低样本权重；
5. 和原始每日采样 baseline 对比。
