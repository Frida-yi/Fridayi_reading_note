# Chapter 2 - Financial Data Structures

## 2.3 Bars

1. 按时间采样得到的序列往往统计性质较差，比如序列相关、异方差和收益非正态（Easley, López de Prado, and O’Hara [2012]）。GARCH 模型在某种程度上就是为了解决这种错误采样带来的异方差问题。

2. 在固定交易笔数下，价格变动可能服从高斯分布；在固定时间区间内，价格变动可能服从稳定帕累托分布，其方差是无限的。由于任意时间区间内的交易笔数是随机的，上述说法并不矛盾。

3. 构造 tick bar 时，要注意异常值。很多交易所会在开盘和收盘时做拍卖。这意味着在一段时间里，订单簿会积累买卖盘而不立即撮合。等拍卖结束时，会在清算价上公布一笔很大的成交，金额可能异常大。虽然这笔拍卖交易在数据里只记为一个 tick，但它的规模可能相当于成千上万个 tick。

4. 现在很难想象，但在 20 世纪 60 年代，数据供应商很少发布成交量数据，因为客户主要关心的是 tick 价格。后来成交量也开始被记录后，Clark [1973] 发现：按成交量采样得到的收益，其统计性质比按 tick bar 采样还要更好一些，也就是更接近 IID 高斯分布。

5. 假设我们要分析一只在某段时间内上涨了 100% 的股票。在这段时间结束时，卖出价值 1000 美元的股票，需要卖出的股数，只有在一开始买入价值 1000 美元时所需股数的一半。换句话说，成交股数取决于实际交换的价值。因此，在价格波动很大的场景里，用成交额而不是 tick 或成交量来采样，是更合理的。

6. 让 dollar bar 比 time、tick 或 volume bar 更有意思的另一个原因是：随着证券生命周期的推进，流通股数量往往会因为公司行为而多次变化。即使已经调整了拆股和反拆股，发行新股或回购股票等动作仍然会影响 tick 数和成交量（2008 年大衰退之后，这类回购尤其常见）。dollar bar 在面对这些公司行为时通常更稳健。当然，你也可以让 dollar bar 的 bar size 不是固定不变的，而是随着时间动态调整。比如：股票可以按公司的自由流通市值动态调整；固收证券可以按未偿债务总额动态调整。

7. 除了如上 bar，还有 Information-Driven Bars。这种 bar 主要是根据市场上的异常成交行为重新建 bar，可以捕获某些知情人的行为。
