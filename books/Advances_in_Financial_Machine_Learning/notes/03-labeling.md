# Chapter 3 - Labeling

## 3.3 Computing Dynamic Thresholds

1. 对于 3 分类任务的 label，对于不同的股票，或者同一只股票的不同时期，应该以过去收益标准差的指数加权平均作为波动率预期；然后以这个波动率预期为锚点，未来收益超过某个正向阈值则标为 1，低于某个负向阈值则标为 -1，否则标为 0。

## 3.4 The Triple-Barrier Method

1. 最常见的标注法是三重障碍法：设定止盈、止损、截止时间三个参数，然后以价格走势和这三个值的交叉作为 label。
2. 不过这套方法主要更适合时间序列交易；截面选股往往更常见的是连续值 label，用来做排序，而不是这种离散值。
3. 时间序列交易需要一个清晰的进场时机标注，所以更需要离散值 label；但三重障碍法的设计思路仍然可以参考。

## 3.6 / 3.7 Meta-Labeling

1. 在开发过程中，将判断涨跌的模型，和判断置信度的模型解耦，分成两个模型，两个任务来做，是一种更常见的形式。这样的话我们不仅可以将这个置信度模型放在这个交易系统中，其他人工交易也可以用它来判断置信度。所以其实可以考虑在截面选股之后，再对前 K 个标的做置信度模型评判，只交易那些置信度高的。

## 3.9 Dropping Unnecessary Labels

1. 标注完 label 之后，要确保 label 的分布是均匀的（仅对于分类任务）。排序任务则应该看每只股票的分数分布，需要让它符合正态分布；实际上现在的 z-score 算法已经做到了这一点。
