# Chapter 9 - Hyper-Parameter Tuning with Cross-Validation

1. 调参时，应该使用交叉验证的方式进行超参数搜索。对超参数的衡量方式，应该用交叉熵损失，因为不仅要看模型预测的正确率，还要看模型预测的置信度和实际涨跌之间的关系，分数打 0.9 然后下跌的错误，和分数打 0.6 然后下跌的错误，不应该是等价的。

2. 传统深度学习的 train/val/test 切分方式在金融数据中有一定的局限性，因为 val set 并不均匀，一旦确定下来，超参数会被拟合到一个固定的时间段和固定的行情上。对于超参数的搜索，应该使用 CV（交叉验证）来进行每个时间段和行情上的均匀超参数搜索。
